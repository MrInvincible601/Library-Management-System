# 5.2 Statement

## Problem Statement

Managing books manually can make it difficult to keep track of which books are available and which books have been issued. This project provides a simple command-line system to manage basic library operations such as adding, searching, issuing, and returning books.

## Scope of the Project

The project focuses on basic library book management using Python. It allows users to maintain a list of books during the program session, search for books, and update their availability status. The project is designed for small-scale use and does not include database storage, user accounts, or online access.

## Target Users

- Students learning Python programming
- Small libraries or classroom libraries
- Users who need a simple way to manage a small collection of books

## High-Level Features

- Add new books with title and author
- Search for books by title or author
- Issue an available book
- Return an issued book
- Display the current status of books
- Simple menu-based command-line interface
